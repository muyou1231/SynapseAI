# SynapseAI 简历文案（精简版）

## 简历正文（直接复制）

**SynapseAI —— AI 能力集成平台（以即时通讯为底座）　独立开发　2026.07 - 2026.09**
技术栈：Spring Boot 3 · Java 17 · MyBatis-Plus · MySQL · Redis · WebSocket · SSE · MinIO · 大模型 API · WebRTC · 原生 JS

- **双通道实时通信**：REST + WebSocket(STOMP/SockJS) 双通道；握手阶段解析 Token 绑定身份，业务侧只信服务端身份；按单播/群播/私有会话分发 Topic，自增 ID 增量补拉 + 指数退避重连，断线消息零丢失。
- **AI 能力集成**：`SseEmitter` 流式输出实现打字机效果；多轮上下文按会话子线隔离，逐 token 回写数据库，刷新可恢复未完成的回复。
- **MCP 可插拔能力框架**：能力以配置行持久化、管理端热启停；内置消息群发助手实现「自然语言 → 结构化 JSON → 收件人解析 → 预览 → 批量发送」的 Agent 化链路。
- **数据与工程**：28 张表 / 66 个索引；自研 MySQL 5.7 幂等迁移模板（存储过程吞异常），25 个增量脚本可重复执行；Redis 分级缓存故障自动回源。

## 核心功能（一行版，按需挑选）

即时通讯（单聊/群聊/已读回执/撤回/搜索）· 好友与群组 · 朋友圈 · 实时通知 · WebRTC 语音通话 · AI 对话与流式输出 · AI 学习空间 · AI 消息群发助手 · 时间胶囊（AES-256-GCM 密态封存，到期解锁）· 隐身阅读 · 消息炸弹 · 积分与亲密度 · 文件/图片/语音存储 · 管理后台（用户冻结封禁、内容审核、公告、AI 与 MCP 配置）
